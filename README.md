Flight-Booking-Travel-Data-Analysis
This project analyzes flight booking data to understand passenger behavior, ticket pricing trends, and airline performance. Using data analysis and visualization techniques, the dashboard provides insights into booking patterns, payment methods, travel classes, and passenger demographics.

📊 Key Insights
Analyzed 250 flight bookings with a total ticket revenue of $0.64M.
The average passenger age is 45.6 years, showing the dominant traveler demographic.
Identified top-performing airlines and departure cities based on ticket revenue.
Compared travel class bookings including Economy, Business, First, and Premium.
Analyzed payment methods such as Credit Card, Cash, Net Banking, PayPal, Debit Card, and UPI.
Visualized ticket price distribution by passenger age and travel behavior.

🛠 Tools Used
Excel / CSV Dataset
Power BI (Dashboard & Visualization)
Data Cleaning & Analysis

📈 Project Outcome
The dashboard helps identify revenue drivers, popular airlines, and booking patterns, enabling better decision-making for airlines and travel businesses.
